# Code of conduct

## Treat people with respect

Use clear and respectful words. Let other people state different views. Give feedback about the work, not the person.

Do not harass or threaten people. Do not publish private information without permission. Do not use sexual comments or images in project spaces.

## Where these rules apply

These rules apply to project issues, pull requests, reviews, and other project spaces. They also apply when a person represents this project in public.

## Report a problem

Send a report to `github@byteland.app`. Give the facts that the maintainers need to review the problem. The maintainers will keep the report private when possible.

## How maintainers respond

Maintainers review each report and select an action.
They can ask for a correction or give a formal notice.
They can also limit participation or remove a person from the project.
They will state the reason to the person when possible.
